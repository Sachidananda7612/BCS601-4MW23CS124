# BCS601-USNXXX – Fibonacci Series Generator

## 📌 Project Description

This is a simple web application developed using Python Flask that generates the Fibonacci series based on user input.

The user enters a number **n**, and the application displays the first **n Fibonacci numbers**.

---

## 🚀 Features

* Generate Fibonacci series
* Simple user interface
* Fast and efficient computation
* Deployed on cloud platform

---

## 🛠️ Technologies Used

* Python
* Flask
* Gunicorn
* HTML

##  How to Run Locally

1. Clone the repository
2. Install dependencies:

   ```
   pip install -r requirements.txt
   ```
3. Run the app:

   ```
   python app.py
   ```
4. Open browser:

   ```
   http://127.0.0.1:5000
   ```

---

##  How It Works

* User inputs a number
* Backend processes using Fibonacci logic
* Result is displayed on the webpage
